# X Media Navigator — TypeScript rebuild (private beta)

X (Twitter) プロフィールのメディアタブから開いた画像・動画を、一覧順に移動する非公式Chrome拡張機能の開発版です。

**状態:** TypeScriptリファクタリングの検証ブランチ。**X実サイトでの動作確認が済むまでリリース不可**。既存のChromeウェブストア版は書き換えません。

## 操作

| 操作 | 挙動 |
| --- | --- |
| `→` | 投稿内に次の画像があれば **X標準の画像送り**。確認できた**最後の画像**からのみ次の投稿へ進む |
| `←` | 投稿内に前の画像があれば **X標準の画像戻し**。**最初の画像**からのみ前の投稿へ戻る |
| `Shift + ← / →` | 拡張による特別な移動はしない（統一した左右キー操作） |
| 画面上の `◀` / `▶` | 常に前後の**投稿**へ移動する専用ボタン |

**先読み:** メディアビューア表示中、既に一覧で確認できた前後の写真を最大2枚までX公式の画像CDNから低優先度で先読みします。動画の全量先読みや外部API呼び出しはしません。省データ設定・低速回線・オフラインでは先読みを停止します。読み込めた画像は可能なら `decode()` も実行します。長いタイムラインでもサムネイルURLの保持を128件までに制限します。現行Xでキャッシュが利用されるかは実機検証が必要です。

**SPAとの違い:** XはすでにSPAです。今回行うのは画像のプリロードで、ビューアを閉じて次の投稿を開き直す瞬間の再描画まで消すものではありません。React内部の未公開APIに割り込まない設計です。

**安全側の判定（v2.2）:** 一部の画像サムネイルだけから「最後の画像」と決め付けません。Xが表示する画像番号/総枚数（例: Image 2 of 2）、または上限4枚すべての添付画像URLを確認できた場合にだけ右キーで投稿移動します。番号が確認できない場合はXの操作を維持します。先頭以外の左キー、動画の左右キーもXに任せます。

**メディアタブ（v2.2）:** `?filter=photo` と `?filter=video` 等を別の一覧として扱います。XのSPAが新タブのDOMを置き換えるまでは古い一覧を新しい一覧と混ぜず、移動を一時停止します。勝手なフィルター切替は行いません。通常時の全件走査はMutationObserverに任せ、450msの確認ごとに全タイルを走査しません。

`/ユーザー名/media` の一覧から開いたビューアでのみ動きます。別プロフィールの投稿や通常の投稿ビューアでは勝手に動きません。

## ディレクトリ構成

- `src/core.ts` — URL・メディア識別子・ショートカットの純粋ロジック
- `src/content.ts` — 状態管理、DOM監視、ナビゲーションの実装
- `extension/` — Chromeが直接読み込む配布用ディレクトリ。JavaScriptは**自動生成**。
- `upstream/chrome-v1.3/` — Chrome v1.3の参照用スナップショット。**編集禁止**。
- `tests/` — 単体・模擬DOM・任意のChromiumテスト
- `docs/analysis/` — 初期コード監査・呼び出し関係
- `docs/MIGRATION_V2.md` — 変更点・リスク・検証の段階
- `docs/IDEAS.md` — 利便性改善の優先順位
- `docs/research/2026-10-25-media-timeline.md` — 2026年の写真/動画タブと画面操作の調査根拠

**[ZIPの入手・導入手順](docs/INSTALL_BETA.md)** にGitHub Actionsからのダウンロード方法を記載しました。実際のChromeを使用する検証表は **[QA_BETA_V221.md](docs/QA_BETA_V221.md)**。ベータZIPを利用するだけならNode.jsやTypeScriptは必要ありません。既存のWebストア版は変更しません。

## 開発・テスト

Node.js 20以上が必要です。

```sh
npm install
npm run build
npm test
npm run check
```

Chromeの拡張機能として読み込むのは **`extension/`** です。TypeScriptファイルを直接読み込むことはできません。
開発版をテストするときはChromeの「デベロッパーモード」から「パッケージ化されていない拡張機能を読み込む」を選択してください。**元のストア版は一時的に無効化**してください。

`XMN_RUN_CHROMIUM=1 npm run test:browser` は、Chromiumが利用できる環境でのみ動く任意の擬似X統合テストです。Xの実サイト検証とは異なります。

## 維持すべき原則

1. TypeScriptを単一の開発正本とし、`extension/content_script.js` は毎回ビルドで更新する。
2. Chrome配布済み原本・既存インストール・ユーザープロファイルには一切書き込まない。
3. 動作していない機能を「修正済み」とせず、静的証拠・自動テスト・X実機確認を分ける。
4. 追加権限や閲覧履歴の保存は行わない。先読みは既存のX公式画像CDNのみを対象とし、外部の開発者サーバーには送信しない。
5. Firefox側のMIT表記とChrome配布物の権利関係を確認するまで第三者公開しない。

初期解析: `docs/analysis/baseline-v1.3.md`。今後の機能案は `docs/IDEAS.md`。
