# X Media Navigator — 固定フォルダのインストールと更新（v2.2.3）

> 非公開の開発ベータです。X本番での全機能は未検証。元のChrome Web Store版はそのまま残します。

## 初回導入（1回のみ）

1. Chromeのテスト用プロフィールで `chrome://extensions` を開く。
2. Webストア版や旧ベータ版と同時に使わないよう、重複する拡張機能を無効化する。
3. デベロッパーモードをオンにし「パッケージ化されていない拡張機能を読み込む」を選ぶ。
4. **`%USERPROFILE%\Downloads\X-Media-Navigator-Current`** を選択する。
5. `X Media Navigator (TypeScript Dev)` のバージョンが `2.2.3` と表示されることを確認する。

## 以後の更新（フォルダを変更しない）

開発時に依頼を受けた私が、TypeScriptの修正→ローカル・CIテスト→GitHubへコミット／Push→
**固定フォルダ内の6ファイルを同じ場所へ反映・照合**する。定期実行タスクや同期プログラムは使わない。

- Chromeの `chrome://extensions` で対象拡張カードの**再読み込み（⟳）**を押す。
- Xの既に開いているタブは、新コードが読み込まれるようにページを再読み込みする。
- 同じフォルダなので拡張を追加し直さない。版番号は `manifest.json` の更新で変わる。
- Chrome画面上部の**「更新」ボタンは非公開GitHubのファイルを取得しない**。
- PCがオフラインのときはGitHubの変更を先行し、PCの固定フォルダは未同期として記録する。

## 実機確認・安全性

- プロフィールのメディアタブから写真を開く。画像途中の左右キーはX標準、最後の画像のみ次投稿へ。
- 写真2〜4枚、日本語UI、フィルター切替、動画、スクロールを重点検証する。
- Xが画像の枚数を明示しない場合、右キーが確認操作となる場合がある。画像が進むなら投稿を飛ばさない。
- 問題が起きたらベータ拡張を無効化し、元のChromeプロフィールで通常版を利用する。
- Cookie、認証トークン、個人情報、非公開投稿のスクリーンショットはGitHubに投稿しない。
- 調査と不具合記録：Issue #14 (https://github.com/ButaMonky/x-media-navigator/issues/14)。
- 自動テストが通っていてもX実サイトでの動作が成功したことにはならない。

## 版管理

GitHubのPR #11と非公開の研究ブランチにコードを保存。安定版 `main` は現時点では変更しない。
Chromeに反映する対象は `extension/` の6ファイルだけ。TypeScriptの開発環境やテストファイルはインストール不要。
