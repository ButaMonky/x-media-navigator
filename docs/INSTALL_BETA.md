# X Media Navigator v2.2.1 ベータ版のインストール方法

> 状態：**非公開・実機検証用ベータ**。Node.js、TypeScript、コマンド操作は**不要**。
> Xの本番サイトでの動作は未検証。Chromeウェブストア版v1.3とは別物です。

## 1. ZIPを入手する（GitHub Actions）

1. GitHubにログインして [非公開リポジトリのActions](https://github.com/ButaMonky/x-media-navigator/actions/workflows/check.yml) を開く。
2. 一覧から **research/media-filter-boundary-v22** の最新の **push** 実行を開く。
3. 右上の検査結果が緑の `Success` であることを確認する。
4. ページ下部の **Artifacts** にある `X-Media-Navigator-v2.2.1-beta1` をクリックしてZIPを入手する。
5. ZIPを任意の新規フォルダ（例：`X-Media-Navigator-Beta`）に展開する。**manifest.jsonが直下にあるフォルダ**が導入先。
6. Artifactsがない場合はその実行が古い・検査失敗・保存期限（30日）切れの可能性があります。**前の失敗版を使わないでください**。

**補足**: GitHub ActionsのアーティファクトはZIP形式なので、別途ビルドやさらにZIPを作成する必要はありません。GitHubの非公開リポジトリにアクセスできるアカウントでダウンロードしてください。

## 2. 安全にChromeへ読み込む

1. Chromeのプロフィールアイコンから、**ベータテスト専用の新しいプロフィール**を作成する（既存の通常利用プロフィールはそのまま）。
2. 新しいプロフィールでアドレスバーに `chrome://extensions` を入力する。
3. 画面右上の**デベロッパーモード**をオンにする。
4. **パッケージ化されていない拡張機能を読み込む**をクリックする。
5. 展開したフォルダのうち、`manifest.json` が入っているフォルダを選択する。
6. `X Media Navigator (TypeScript Dev)`、バージョン **2.2.1** が表示されれば読み込み完了。

同じプロフィールにWebストア版がある場合は、**同時有効化しないこと**（左右キーやDOM操作が競合します）。**元の拡張ファイルを直接書き換えたり、削除したりしないでください**。

## 3. 優先的な実機確認

詳細なチェック表：[`QA_BETA_V221.md`](QA_BETA_V221.md)。

- `https://x.com/<公開ユーザー名>/media` の一覧から画像を開く（画像の投稿直リンクからではありません）。
- 画像1〜4枚で、**途中はX標準の左右キー**、**最後の画像で→なら次の投稿**、**最初の画像で←なら前の投稿**。
- 写真／動画タブの切替、動画のシーク、一覧の続きをスクロールしてから移動、戻る操作を確認。
- Xが画像の総枚数を示す確かな情報を公開していない場合、右キーで次の投稿へ進まないことがあります。意図しない投稿移動を防ぐための仕様です。

## 4. 失敗したら・戻し方

- `chrome://extensions` からベータ版のスイッチを**オフ**にするか、ベータテスト専用プロフィールを閉じる。
- 元の通常利用プロフィールとWebストア版には一切の変更がない設計です。
- GitHub [Issue #13](https://github.com/ButaMonky/x-media-navigator/issues/13) に、操作・期待値・実際の結果・Chromeのバージョン・Xの表示言語を記録。
- Cookie、認証ヘッダー、プライベートな投稿、個人情報を添付しない。

## 5. ビルド・配布の取り扱い

このZIPは **Chromeウェブストアに公開された拡張機能でも、署名済みCRXでもありません**。GitHub ActionsがTypeScriptをコンパイルし、Node・模擬DOM・Chromiumの検査が成功したときだけ、必要なChrome用ファイル6件をZIPにまとめています。

ベータ配布を非公開のまま維持し、X本番の動作確認が済むまで `main` への統合や公開Releasesを行いません。別のベータZIPを読み込む場合は、同じChrome拡張のフォルダの内容を勝手に上書きせず、版と動作を照合してください。
