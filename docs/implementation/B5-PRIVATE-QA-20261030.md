## B5受入基準（ログイン済みXが必要）

1. Xユーザーの公開メディア一覧から、
   例示された「投稿28/28」を超えて投稿29へ**左右1回操作**で移動可能か。
2. 1/2/3/4枚の画像と、1投稿の最終画像→次投稿で
   キーを重ねずに移動できるか。前投稿へ戻る動作も確認。
3. GIF・動画・混合メディアをX純正操作と区別して扱い、
   存在しない`/video/N`や`/photo/N`を推測しないか。
4. 元のX返信欄、左右・フルスクリーン・ショートカット・
   画像表示品質とアニメーションが保持されるか。
5. 低画質プレビュー→高画質への切替で黒画面・別投稿表示・
   大量ダウンロードが発生しないか。
6. 450件超の完結投稿群をWorkerに保存した後、次・前ページへ移動し
   戻ったときもUIが正しいか。ここはフル文書移動で、
   X React SPAと同等の滑らかさは未達。
7. API取得不能／X非ログイン／ネットワークオフ／
   古いセッションでは、操作不能や安全制限迂回を起こさないか。
