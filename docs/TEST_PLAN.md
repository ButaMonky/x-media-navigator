# テスト計画（初回監査）

テスト可能なものから自動化し、実サイト確認と混同しないこと。`test.todo` は未検証項目。

## キー操作・画像ビューア
1. 投稿Aの画像1/4で右キー → Aの画像2/4（投稿Bに飛ばない）。
2. Aの画像4/4で右キー → X標準の挙動を維持（境界を勝手に飛ばさない）。
3. 投稿Aの画像2/4で左キー → Aの画像1/4。
4. 提案ショートカット Shift+左右で投稿移動。正式仕様決定後に固定。
5. 入力欄・検索窓にフォーカスがある時は投稿移動しない。
6. 動画を再生中の左右キーはX動画プレイヤーのシークと競合しない。
7. 矢印キー押しっぱなしやダブルクリックで移動が重複しない。

## データ・遷移
8. 同一投稿の写真4枚を投稿IDとメディア番号で区別する。
9. 同一投稿に複数メディアがあってもタイルの順序を再現できる。
10. SPAでDOMが再生成されても古い要素をクリックしない。
11. アカウントを切り替えると番号とマップが正しく初期化される。
12. 長いメディア一覧で無限スクロール後の項目を確実に待機する。
13. 最後のタイルで追加項目がない時、同じタイルへ誤遷移しない。
14. `/media` → `/status/N/photo/K` → 戻る → 別の投稿でも動作する。
15. 英語UIで閉じる・前へ・次へが正しく動作する。
16. X以外のタブやプロフィール外で余計なキー処理を行わない。
