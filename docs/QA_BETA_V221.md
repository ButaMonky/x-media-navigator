## 先読みの実測

Chrome DevTools → Network → Preserve log ON、Disable cache OFFにして、`pbs.twimg.com/media/` の画像URL、サイズ指定（`name=large`等）と表示URLが一致するか確認します。Image.decode()で読み込み完了しても、X表示時に別URLを使用すれば再利用されない可能性があります。ネットワーク転送サイズが0でも、クロスオリジン制限のため「キャッシュ命中」とは断定できません。
